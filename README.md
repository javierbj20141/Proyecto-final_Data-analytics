**Objetivo**:

El objetivo de este proyecto fue analizar una base de datos de productos de comercio electrónico con el fin de identificar patrones, tendencias y características relevantes para la toma de decisiones. Para ello, se trabajó con diferentes fuentes de datos que contenían información sobre los productos y sus categorías, integrándolas y transformándolas para facilitar su análisis.
El propósito final fue combinar técnicas de preparación y análisis de datos mediante **Pandas** con la creación de un **dashboard interactivo en Power BI**, permitiendo transformar los datos en información útil y visualmente accesible para el usuario.

**Metodología**:

El proyecto comenzó con la carga y exploración de los conjuntos de datos, integrando la información de productos y categorías mediante el uso de Pandas. Posteriormente, se llevó a cabo una fase de limpieza, validación y transformación de datos, revisando valores nulos, tipos de datos y creando nuevas variables que facilitaran el análisis posterior.
Una vez consolidada la base de datos, se realizó un análisis exploratorio utilizando diferentes técnicas de agregación y segmentación para identificar patrones relevantes y extraer conclusiones significativas. Los resultados obtenidos se documentaron de forma paralela en un informe de análisis.
Finalmente, se desarrolló un dashboard en Power BI compuesto por varias páginas orientadas a la visualización de resultados y al análisis interactivo. Para ello se utilizaron medidas personalizadas, columnas calculadas, tablas auxiliares, filtros dinámicos, marcadores y tooltips, con el objetivo de facilitar la interpretación de los datos y la exploración de los principales hallazgos obtenidos durante el análisis.
